# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Short version: be kind, be constructive, assume good faith. Harassment,
personal attacks, and derailing are not welcome anywhere in this project's
spaces.

Report conduct issues to hhamaker22@gmail.com. Reports are handled
confidentially.
