# Crew Desktop App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Crew", a local PySide6 desktop app that runs LLM coding agents (with `/goal` orchestration and a pixel-art crew stage) per `python-desktop-rebuild.md`.

**Architecture:** UI-free async `engine/` package (providers, tools, runner, store, agents, permissions) exposed to a PySide6 `app/` layer through a typed event stream + facade. SQLite persistence. Spec file `python-desktop-rebuild.md` in repo root is the authoritative spec; tasks below cite its sections rather than duplicating content.

**Tech Stack:** Python 3.12, PySide6, qasync, aiosqlite, pydantic v2, anthropic, openai, httpx, markdown-it-py, pygments, watchfiles, ripgrep.

## Global Constraints

- Python 3.12+ (`/opt/homebrew/bin/python3.12`), venv at `.venv`, deps in `pyproject.toml`.
- Hard rule (spec §3): `crew/engine/` must not import Qt; enforced by a unit test.
- Storage: SQLite WAL at `~/.crew/crew.db` (path injectable for tests).
- Config: two-layer deep merge, project wins; programmatic writes are key-by-key patches preserving file text (spec §4.1).
- Tool output truncation: 30k chars head+tail, full output to `~/.crew/tool-output/<id>.txt` (spec §5.4).
- Orchestrator prompt and `/goal` template used verbatim from spec §6.2/§6.3.
- Tests: pytest + pytest-asyncio; engine fully unit-testable without Qt or network (fake provider).
- Commit after each green milestone chunk.

## Milestone 1 — Engine core (spec §9.1)

### Task 1: Project scaffold
Files: `pyproject.toml`, `.gitignore`, `crew/__init__.py`, package dirs, `.venv`.
Steps: create venv with python3.12; install pyside6 qasync aiosqlite pydantic anthropic openai httpx markdown-it-py pygments watchfiles pytest pytest-asyncio; commit.

### Task 2: Config (spec §4.1–4.2)
Files: `crew/engine/config.py`; Test: `tests/engine/test_config.py`.
Produces: `load_config(project_dir) -> Config` (pydantic model per §4.2 schema), `deep_merge(base, override)`, `patch_config_file(path, updates: dict[str, Any])` where dotted keys patch nested values while preserving comments/trailing commas/formatting of untouched lines, `lenient_json_loads(text)` (strips `//` comments + trailing commas).
Tests: merge precedence (project wins per key), lenient parse, patcher round-trip preserving comments, permission schema normalization (`"allow"` str vs `{default,allow,deny}` object).

### Task 3: Store (spec §5.1)
Files: `crew/engine/store.py`; Test: `tests/engine/test_store.py`.
Produces: `Store` (aiosqlite, WAL) with async CRUD: `create_project/get_project_by_path`, `create_session/get_session/list_sessions(project_id)/update_session`, `add_message/update_message`, `add_part/update_part/list_parts(session_id)`, `set_todos/get_todos`. Tables exactly per §5.1. Part payloads JSON per §5.1 part types.
Tests: round-trip session/message/parts ordering, parent_session_id children query, todo replace.

### Task 4: Permissions (spec §8)
Files: `crew/engine/permissions.py`; Test: `tests/engine/test_permissions.py`.
Produces: `PermissionPolicy.resolve(tool, arg) -> "allow"|"ask"|"deny"` (deny-list → allow-list → default; bash globs match command, edit/write match paths), per-agent override layering, presets `SAFE/ASK/FULL_AUTO`.

### Task 5: Provider adapters (spec §5.2)
Files: `crew/engine/providers/base.py`, `anthropic.py`, `openai_compat.py`, `catalog.py`; Test: `tests/engine/test_providers.py`.
Produces: event dataclasses (`TextDelta, ReasoningDelta, ToolCallStart, ToolCallDelta, ToolCallEnd, Usage, Done, ErrorEv`), `ModelRequest`, `Provider` protocol, `AnthropicProvider`, `OpenAICompatProvider`, `FakeProvider` (scripted events, for tests), retry wrapper (backoff on 429/5xx/network, 4 attempts, emits retry signal), static `CATALOG` dict + config extension, `resolve_model("provider/id", config) -> (Provider, model_id, ModelInfo)`.
Tests: fake streaming assembly, retry/backoff logic (injected failures), catalog resolution. Real SDK adapters translate events only — thin, tested via stubbed SDK stream objects.

### Task 6: Tool framework + file tools (spec §5.4)
Files: `crew/engine/tools/base.py`, `read.py`, `write.py`, `edit.py`, `glob.py`, `grep.py`; `assets/prompts/<tool>.txt`; Test: `tests/engine/test_tools_files.py`.
Produces: `Tool` base (pydantic `Params`, `execute(params, ctx) -> ToolResult(output, title, metadata)`), `ToolContext` (cwd, session_id, read-file registry, store, events, permission asker), truncation helper (30k head+tail + sidecar file).
Tests: read numbering/offset/limit/missing, write requires-prior-read on overwrite + parent dir creation, edit unique-match/ambiguous/not-found/replace_all, glob newest-first cap 100, grep rg+fallback parity on fixture tree, truncation boundaries.

### Task 7: bash, webfetch, todowrite, question tools (spec §5.4)
Files: `crew/engine/tools/bash.py`, `webfetch.py`, `todowrite.py`, `question.py`; Test: `tests/engine/test_tools_exec.py`.
Produces: bash via `asyncio.create_subprocess_shell` (cwd=project, merged stdout/stderr + exit code, timeout default 120s max 600s, process-tree kill via start_new_session+killpg), webfetch (httpx, 5MB cap, html→markdown), todowrite (replaces store todos, emits `todo.updated`), question (suspends on asyncio.Future resolved by `question.asked` answer).
Tests: bash echo/exit-code/timeout-kill, todowrite persistence+event, question future resolution; webfetch html→md via local content (no network).

### Task 8: Agent registry + commands (spec §4.3–4.4, §6.1)
Files: `crew/engine/agents.py`, `crew/engine/commands.py`, `assets/prompts/{build,plan,orchestrator,general,explore}.txt`, built-in command defs; Test: `tests/engine/test_agents.py`.
Produces: `AgentDef` (frontmatter fields per §4.3), registry: built-ins (§6.1 table) + global/project `agent/*.md` discovery, same-name merge-over-builtin, config `agent.<name>` overrides on top; `CommandDef` + built-ins `/goal /compact /new /model /agents` (goal template verbatim §6.3); `$ARGUMENTS` substitution; watchfiles hot-reload hook.
Tests: frontmatter parse, discovery+override precedence (config > project file > global file > builtin), command template substitution, orchestrator tool restrictions (no edit/write).

### Task 9: Runner + events + task tool + compaction (spec §5.3, §5.5, §5.6)
Files: `crew/engine/events.py`, `crew/engine/session.py`, `crew/engine/runner.py`, `crew/engine/compaction.py`, `crew/engine/tools/task.py`, `crew/engine/facade.py`; Test: `tests/engine/test_runner.py`.
Produces: engine event types (§5.6 names), `Engine` facade (`open_project`, `submit_prompt(session_id, text, agent, model)`, `abort(session_id)`, `answer_permission/answer_question`, `events` async queue); runner loop per §5.3 (system prompt assembly w/ env block + instruction files, history minus pre-compaction, streaming persist, concurrent tool exec with bash/edit/write serialized, steps cap, queued prompts, title via small_model); task tool (child sessions, task_id continuation, parallel, no task tool inside subagents); compaction at >85% window + `/compact`.
Tests (FakeProvider): full turn with tool call persists parts+events in order; parallel task calls create child sessions; task_id reuse continues child; abort marks pending tools error; compaction inserts summary and prunes sent history; title generation.

### Task 10: CLI harness
Files: `crew/cli.py`; manual check: `python -m crew.cli "prompt"` runs a session in terminal (engine only). Commit milestone 1.
